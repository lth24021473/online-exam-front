Cho đoạn mã nguồn triển khai thuật toán đệ quy sau đây trong ngôn ngữ C++. Hãy xác định độ phức tạp thời gian tiệm cận trường hợp xấu nhất (Worst-case Time Complexity) của hàm computePath(n).

Lưu ý: Giả sử kích thước đầu vào n là số nguyên dương và các lời gọi đệ quy đều thoả mãn điều kiện dừng của hàm cơ bản.

C++20 Strict Mode 
#include <iostream>
long long computePath(int n) {
    // Trường hợp cơ sở
    if (n <= 1) {
        return 1;
    }
    
    // Vòng lặp phân rã kích thước n
    long long sum = 0;
    for (int i = 1; i < n; i *= 2) {
        sum += i;
    }
    
    // Phân nhánh đệ quy nhị phân
    return sum + computePath(n - 1) + computePath(n - 2);
}
